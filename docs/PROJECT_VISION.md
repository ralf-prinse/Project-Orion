# Mission

Project Orion exists to provide traders with a professional, deterministic decision-support platform for the United States stock market.

The platform is designed to assist decision making through transparent calculations rather than replacing human judgement.

---

# Vision

The long-term vision of Project Orion is to become a professional, deterministic desktop trading platform that combines high-quality market analysis with a modern, modular and maintainable user experience.

The platform is designed around a layered architecture in which deterministic services, presentation models and desktop workspaces remain strictly separated.
Every recommendation produced by Orion should be:

- Deterministic
- Explainable
- Reproducible
- Testable
- Transparent

---

# Core Principles

Project Orion is built around several non-negotiable principles.

## Deterministic Decision Support

Trading recommendations are generated through deterministic calculations.

Artificial Intelligence never creates investment decisions.

---

## Architecture First

Long-term architecture always takes priority over short-term implementation speed.

Technical debt should be minimised whenever practical.

---

## Professional Engineering

Project Orion is developed as a professional software product.

Every implementation should be maintainable, modular and independently testable.
The desktop application should evolve through reusable workspaces, presenters and presentation models rather than tightly coupled user interface code.

Architecture should remain stable while individual components can evolve independently.

---

## Explainability

Every recommendation should be traceable back to its underlying calculations.

Users should understand why Orion produced a recommendation.

---

## Separation of Responsibilities

Business logic remains independent from presentation.

The GUI displays information but never performs trading calculations.

---

# Target Users

Project Orion is intended for:

- Private investors
- Swing traders
- Technical analysts
- Professional traders seeking transparent decision support

---

# Long-Term Goals

Future versions of Orion may include:

- Professional desktop workspace
- Multi-monitor support
- Broker integrations
- Watchlists
- Alerts
- Advanced reporting
- AI-assisted explanations
- Plugin architecture

These features must remain consistent with the architectural principles of Orion.

---

# Product Philosophy

Project Orion is not designed to replace traders.

It is designed to make traders better informed.

Transparency is preferred over complexity.

Consistency is preferred over cleverness.

Architecture is preferred over shortcuts.

---

# Success Criteria

Project Orion is considered successful when it provides:

- Reliable deterministic analysis
- Professional desktop experience
- High software quality
- Excellent maintainability
- Clear explanations for every recommendation
