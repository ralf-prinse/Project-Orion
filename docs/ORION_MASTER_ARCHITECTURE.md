# System Philosophy

Project Orion is a deterministic AI-assisted desktop trading platform.

The deterministic backend is considered production stable.

The desktop frontend is now evolving into a reusable professional visualization framework.

Every architectural layer owns exactly one responsibility.

Business logic never leaks into presentation.

Artificial Intelligence never performs calculations.

Artificial Intelligence only explains deterministic outputs generated by the TradingPipeline.

The TradingPipeline remains the single source of truth.

---

# Core Principles

## Deterministic First

Every trading decision must be:

- deterministic
- reproducible
- traceable
- explainable

Random behaviour is forbidden.

Artificial Intelligence may never generate trading decisions.

# ChartCanvas Framework

The ChartCanvas Framework is the reusable visualization engine of Orion.

The framework separates:

- widget composition
- canvas composition
- painting
- drawing
- overlays

Each concern is isolated into its own architectural layer.

The framework is reusable across all desktop workspaces.

# ChartCanvas Framework

The ChartCanvas Framework is the reusable visualization engine of Orion.

It replaces widget-owned painting with a layered rendering architecture.

Widgets no longer paint charts directly.

Instead, widgets delegate rendering to ChartCanvas.

The framework guarantees:

- reusable rendering
- presentation-only drawing
- strict separation of responsibilities
- extensibility
- consistency across all workspaces

- identify the current sprint;
